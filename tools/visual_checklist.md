# 截圖目視清單（G0.1 起，每次出包都要過）

每次 build：`tools/run_build.sh` 會出低／中 × 日／夜截圖。報告前用人眼對呢份清單睇圖，唔好只靠像素抽樣。

## 要睇嘅圖
- 低＋中畫質，日＋夜
- 闊度 390（設計）、412、768
- 寵物喺物件**前面**同**後面**（樹、小屋）——驗遮擋

## 清單
1. 寵物浮起或沉入地下
2. 影唔見咗或形態不對（低檔應有腳底圓影；唔好係實心方塊）
3. 精靈邊緣光暈／白邊（halo / fringe）
4. 閃爍或 z-fighting（地平面疊層、板同地交界）
5. 遮擋錯誤（應該被樹／屋擋住時冇擋，或相反）
6. 比例錯或精靈被拉闊／拉長
7. 鏡頭裁走大物件（樹頂、屋簷）或望穿地平
8. UI 重疊、字被切走、按鈕出界
9. 像素模糊（錯 filter／3D 縮放雙線性／不該開的 AA）
10. 顏色或曝光錯（發白、過暗、夜晚唔夠夜、米色清屏）
11. 空洞或黑塊（冇地、冇天、破面）

## 報告
- **已發現並已修**：每一項附修前／修後截圖路徑
- **已發現、尚未修**：寫低現象同點解呢輪唔改

## M1a 玩法圖（每次 build 都要睇）
- `m1a-overview.png`：花園填滿畫面闊、寵物高 ≥10%、精靈整數像素倍（唔閃）
- `m1a-follow.png`：撳寵物之後跟拍放大，寵物高 ≥20%，寵物垂直約 55–60%，天空 ≤25%
- `m1a-bubbles.png`：主寵頭頂有需要泡泡（無文字）；細佬／訪客頭頂唔好有同樣需要泡泡
- `m1a-care.png`：底欄一鍵餵／執／摸，同總結卡（icon＋數字、少字）
- `m1a-family.png`：家人自主互動（一齊行／玩等），無文字對白

呢輪**唔使**為燈光、小屋、樹、夜 multiply 再打磨；只記明顯阻擋玩法嘅問題。
