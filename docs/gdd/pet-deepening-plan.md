# 《微光小圃》加深方案（一頁）v1

**診斷（Kurt 試玩）**：外觀好，但①循環單一（條跌→按掣補）②節奏無變化③寵物企喺度、無生命感。
**原則**：先令寵物「似活」，再加驚喜同變化；唔加變現、唔加死亡；全部本機、無後端。

## 三個套餐（含遊測約 12%）
- **A 先救「悶」（建議）**：模組 1＋2＋3a＝20.7 人日＋測 2.5＝**約 23 人日**；程／美／音並行約 **2.5–3 週**。直接解決「企喺度」同「單調」。
- **B 完整加深**：A 改全套動畫＋3b＋4＋5＝46.6＋測 5.6＝**約 52 人日**，約 **5 週**。
- **C 全量**：B＋6＝49.6＋測 6＝**約 56 人日**，約 **5.5 週**。

## 風險
- 美術係瓶頸（M1 已滿載）：A 縮減版＝團絨 3 形態，①②④ 全做、③ 走／玩耍、⑤ 曬太陽／碰花盆、⑥ 3 款，含共用道具 0.8。其餘三隻：首形態 3.8、每新增形態 1.4（四隻全做 44.7，唔建議）。
- 規格（遊美）：分層骨架模板，固定 pivot 底部中心，clip 幀數表通用；每形態 atlas ≤1024×1024，同時只載入當前寵物，貼圖預算 ≤16MB。
- 工時未讀 MVP code，遊程需用 1 日確認狀態機同事件系統可否掛入現有代碼。
- 事件過多會重複：池 8 個起步，每個有冷卻，上線後按遊測數據補。
