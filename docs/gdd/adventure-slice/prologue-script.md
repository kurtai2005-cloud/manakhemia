# 序章劇本：〈風有脈〉

> 遊策｜週 1｜草稿 v1｜全原創｜給：遊程（流程／觸發）、遊美（鏡頭與表情）、遊音（BGM／stinger 提示）、遊測（可跳過／斷點測試）
> 體裁：旁白用書面語、角色對白用口語粵語；`{player}`＝玩家自取名字（預設「旅人」）。每段對白 ≤6 句、可點擊推進／長按快進／整段跳過。對話節點 id 對應 `d_elder_intro`（見 dialogue-format.md、npc-dialogue.md）。

**序章目標**：①帶出主角（見習育成師）；②帶出世界（風谷、風脈、喚風祭）；③交付第一隻野靈（苔團）；④指出第一個目標賽事（初葉盃・初戰）及下一步（去迴風場報名）。
**預計時長**：約 2.5–3 分鐘（可跳過）。**場景**：開場字幕 → 晨苔鎮南門外路（出生點）→ 廣場水井。

---

## P0　開場字幕（黑底、風聲；BGM 未起，只有風聲 ambience）

> 風谷的人說，風有脈。
> 風脈在山脊、在地底、在每一條小路下面流動，把氣流送到谷中每個角落。
> 野靈借著風奔跑——牠們不是被馴服的，是被風叫出來的。
> 可是這幾年，風脈一年比一年弱了。

*（字幕逐句淡入，每句約 2 秒；最後一句後停 1 秒，鏡頭由黑切入晨苔鎮。）*

## P1　抵達晨苔鎮（玩家可操作；教學提示出現）

**旁白**：你背著一個舊布袋，沿著石徑走進晨苔鎮。路旁的青苔軟軟地鋪滿了牆腳，連屋簷上都長著小小的蕨葉。
**旁白**：迴風場門樓上的旗子慢慢飄著，飄得比你想像中慢。街上很靜，只聽見遠處迴風場傳來木板被風拍響的聲音。
**{player}**：「就是這裡了。見習育成師的第一站。」
**{player}**：「信上說，鎮上的村長會在廣場等我。」
**【教學提示】**：點一下地面，就可以走過去。
**旁白**：廣場中央有口老井，井邊站著一位拄著竹杖的老人，彷彿已經等了很久。
**【任務更新】**：與井邊的老人說話。

*（玩家走進廣場區域 `ev_elder_intro` → 自動起動 P2。）*

## P2　老鐘（對話 `d_elder_intro`）

**老鐘**：「你就係寫信嚟嗰位見習生？{player}，啱唔啱？我係老鐘，呢條鎮嘅村長——名頭大，其實就係日日睇住迴風場嗰兩面旗嗰個。」
**老鐘**：「你睇吓迴風場門樓嗰兩面旗。以前一陣風就獵獵作響，而家要等成半日。風脈弱咗，野靈跑唔郁，成條鎮都靜晒。」
**老鐘**：「所以今年谷入面要辦喚風祭。每個鎮辦一個盃賽，冠軍就得一枚風印；集齊三枚，就可以去風眼，將風脈喚返嚟。」
**{player}**：「我只係見習生，幫得上忙嗎？」
**老鐘**：「幫唔幫得上，跑過先知。」

**旁白**：老鐘從腰間解下一個小竹籃。籃子裡，一團圓滾滾的苔綠色小東西打了個呵欠。
**旁白**：牠睜開眼，看了你一眼，又閉上。

**老鐘**：「牠叫苔團。跑得唔算快，不過脾氣好，肯聽人講。我退咗休就冇再帶隊，交畀你啦。」

**【取得野靈：苔團（Lv3）】**（獲得 jingle；命名視窗，可略過）

**【選項】**（只影響下一句反應，唔影響劇情）
- 〔A〕「牠看起來好睏。」→ **老鐘**：「哈哈，苔團同我一樣，要曬夠太陽先郁得。你耐心啲。」
- 〔B〕「我會好好照顧牠。」→ **老鐘**：「好。野靈識分邊個係真心嘅，你一定行得好遠。」

**老鐘**：「仲有，接力賽最少要兩隻野靈輪流跑。你而家得一隻，唔夠㗎。」
**老鐘**：「出鎮向東行，蕨影小徑嗰邊有隻野生嘅碎石獾，常常喺空地度發呆。同佢跑一場，贏咗就可以結緣，佢就係你嘅隊友。」
**老鐘**：「跑輸都唔使驚，佢唔會走，隔一陣再試就得。」

**老鐘**：「記住，野靈唔使你牽住佢跑。你企喺場邊睇住，啱嘅時候叫佢換人、放招，就係育成師嘅本事。」
**老鐘**：「初葉盃新手可以直接報名。去迴風場搵報名處嘅桑姨，佢會教你點入場。」
**【任務更新】**：目標：①去蕨影小徑結緣第二隻野靈　②去迴風場報名初葉盃（初戰）。（順序不限；未有 2 隻不能報名接力）

## P3　結尾（鏡頭）

**旁白**：門樓上的旗慢慢揚起半幅，停了一下，又揚。
**旁白**：苔團在你腳邊打了個噴嚏，吹起一小撮苔絮，飄向迴風場的方向。
**旁白**：你低頭看著牠圓圓的背，忽然覺得，這陣風雖然慢，卻好像認得你。
**{player}**：「走吧，苔團。先找第二位隊友。」

*（鏡頭拉遠到廣場全景，畫面左下角出現「任務」圖示；`prologue_done=true`；自動存檔；城鎮 BGM 維持。）*
