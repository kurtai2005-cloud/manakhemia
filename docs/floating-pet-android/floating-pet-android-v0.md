# 微光小圃｜Android 浮動團絨 v0（評估稿，未開工）
## 觸發
- App 設定開「浮動團絨」→ 跳系統權限頁（SYSTEM_ALERT_WINDOW）；未授權就唔開。
- 離開 app 先出現；返入 app 自動收起。常駐通知可一鍵收起。
## 行為（用生命感精簡集，唔加新動作）
- 細尺寸約 48dp，沿螢幕底邊／側邊行，唔擋中間內容。
- 行、邊行邊望、停低、抓癢、噴嚏、瞓覺；燈泡跟心情色；時段跟 H1–H4 色調（夜晚多瞓少郁）。
- 點一下：回頭＋「咦」；長按：拖去其他位置（拖去底部 × 區＝關閉）；雙擊：開 app。
- 全螢幕 app／彈鍵盤時自動縮埋邊。
## 同 app 狀態同步
- Overlay 只讀存檔快照（形態、心情、需求），唔改核心數值。
- Overlay 唔派獎勵、唔出事件、唔計保底；互動只記入 queue，返 app 時結算（例如「喺外面摸咗佢 3 次」日記），防刷。
- 離線補抽、時鐘規則不變。
## 電量／系統限制
- 動畫 ≤15fps，靜止時 2–5fps；熄螢幕即停；省電模式只顯示靜止圖。
- 60 分鐘冇互動自動入睡（靜止）。
- Android 8+ 必須前景服務＋常駐通知；Android 13+ 要通知權限。
- 風險：Google Play 視 SYSTEM_ALERT_WINDOW 為敏感權限，要聲明用途；小米／華為等廠商要額外開權限。
## 活動模式（設定，Kurt 10-31 補）
1. 邊緣行（預設）：沿底邊／側邊。
2. 自訂範圍：拖四角調大細、拖中間改位置；最細 120×120dp；有預覽框。
3. 全畫面自由行：避開狀態列、導航列；彈鍵盤時縮去邊。
4. 定點：拖放到任何位置停定，原地照做表情／小動作。
- 切換：設定頁＋常駐通知「定點／行走」快捷掣；長按團絨出小選單。
## 玩法影響
- 唔改四項需求、唔改照顧質素、唔影響進化。
- 只加少少心情：每次互動 +1，每日上限 +5；唔派獎勵、唔出事件。
- 需求 <30：頭頂出需求小圖示，點就開 app。
- 待發生事件／閃光日：頭頂 ✨ 小泡泡，點開 app；唔彈窗、唔額外推送通知。
## 必要動作／表情
行、邊行邊望、點一下回頭、待機、瞓覺、抓癢、噴嚏、開心、連點 5 下 grumpy_tap；新增「被拎起」姿勢 1 個 clip（拖動時用）。
## 遊程技術評估（10-31）
- 路線：Capacitor 包 web build＋Kotlin plugin（前景 Service＋TYPE_APPLICATION_OVERLAY），原生 Canvas 畫預烘 atlas（唔用 WebView）；窗口＝寵物大細，其餘觸控穿透。
- 同步：game 唯一模擬者，存檔寫快照到 Preferences；overlay 互動寫 queue（有上限），app resume 取走行離線重播；overlay 唔派獎。
- 人日約 12（10–14）。排第三段後；Capacitor＋APK 1.5 日可插第二段後空檔。
- 風險：Play 權限／前景服務審核、國產機殺背景、Android 14+ 規則、耗電、自由行遮按鈕（預設沿邊，自由行做開關＋一撳停定）。
