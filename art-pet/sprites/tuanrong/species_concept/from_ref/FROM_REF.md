## 做法（`tools/build_from_ref.py`）
1. **切格**：每格向內縮 7px（避開格框線同面板邊），標籤喺格外面，唔使處理。
2. **背景模型**：取同邊界相連、近邊界中位色嘅像素，用遮罩高斯模糊（r=22）估一個平滑背景；做兩輪（第二輪用第一輪前景外擴 8px 以外嘅位重估），避免深藍身體（例如 G3）污染背景。
3. **分類**：同背景色差 >40 = 主體（alpha 255）；閉運算（r=3）判斷封閉範圍，封閉入面嘅洞如果平均色差 ≥22 就填返做主體，近背景色嘅洞（例如觸手之間）保持透明。
   主體外 9px 內、色差 16–52 = 柔光（alpha 60/110/170），顏色用反混合（un-blend）除返背景，所以換底色都唔會帶紫邊。
4. **去角落 icon**：第 1 階格左上 (0..90, 0..90) 用 icon 框底色做背景；完全喺框（+12px）內嘅元件刪走、框線細線刪走；H1 隻角跨過框邊，保留咗。
5. **量化**：每隻主體 median-cut ≤48 色（全解析度做，再降採樣，JPEG 噪點唔會帶入）。
6. **降採樣**：統一比例 ≈300→64（0.21），每格 64px 用眾數（深色 outline 輕微加權）；alpha 用多數決（主體 ≥42% 先算主體）。
   太大嘅隻（B3、C3、D1–D3、E1、E3、F3、G3、H2）自動縮細到入框（比例 0.175–0.20），所以唔係全部同一比例。
7. **擺位**：主體 bbox 水平置中（x=32），底部對齊地線 y=60；之後清單點孤立像素、補 1px 洞。
8. **燈泡**：已有光源當燈泡 = **B1 燈籠、F1 星星天線、G1 星星天線、H3 光環**。其餘 20 隻喺頭頂加細燈泡（深啡外框、黃芯、白高光、短深色莖、柔光 60/110），位置自動搵頭頂；D1/D2/E3 移去火焰左邊石頭頂、F3/G3 移去月亮左邊個頭。

## 檢查
- 24 張全部 64×64；alpha 只有 {0,60,110,170,255}；主體 ≤48 色＋燈泡 6 色（≤54）；冇貼邊；重建結果一模一樣（md5 相同）。

## 每隻備註／問題
| 隻 | 備註 |
|---|---|
| A1–A3 | 泡泡保留；A2/A3 細泡泡縮到 1–2px，有少少碎。 |
| B1 | 燈籠柔光保留（白底睇係淺灰藍光暈）。 |
| B2 | 觸手之間保持透明；綠色發光點保留。 |
| B3 | 珊瑚角＋泡泡保留；燈泡坐喺鯨角頂附近，同珊瑚角有啲擠。 |
| C1–C3 | 火星粒保留；C1 燈泡喺火焰尖，略突兀。 |
| D1–D3／E3 | 深色石邊對紫底分得清；細火星保留；縮細比例較大（0.175–0.19）。 |
| E1–E2 | OK。 |
| F1／G1 | 原有星星天線光暈係半透明，白底睇偏灰（un-blend 後嘅顏色），深底正常。 |
| F3／G3 | 第一版 G3 左半身被當咗柔光（背景模型被深藍身體污染），已經用兩輪背景模型修好。 |
| H1 | 角落 icon（月亮）已刪；隻角跨過 icon 框，保留咗；第一版有一粒 icon 殘留，已經修好。 |
| H2 | 環帶柔光部分保留，最外邊幾粒閃粉偏淡。 |
| H3 | 光環當燈泡；彩色身體細節最多，64px 會失啲細節。 |

整體限制：原圖係 JPEG、像素格唔一致（約 5.0–6.6px／格），降到 64px 會有少少像素不均勻；呢批唔係逐格對準嘅原生像素畫。
