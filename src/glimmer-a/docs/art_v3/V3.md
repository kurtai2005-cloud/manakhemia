## 兩個方向
**V3-A 金光現代 HD-2D（推薦）**：深藍煙燻磨砂面板、1.5px 金幼線同菱形小飾、明朝體（Noto Serif CJK TC Bold）做名同標題，其他字用黑體。頂部用漸層遮罩，唔用硬框。行動掣係煙燻圓形加色環；dock 係懸浮膠囊，選中嗰格有金色柔光同底線。場景係午後金光：暖色調色、體積光、燈泡串 bloom、星芒、螢火光點。整體似 Octopath Traveler II／Triangle Strategy 嘅現代 HD-2D 介面。
**V3-B 晨光玻璃極簡**：白色磨砂玻璃卡、大圓角、金幼內線，深墨色字。四項需要改做環形量表，XP 改做頭像外圈弧線；行動掣收埋一條浮動玻璃膠囊，dock 做白色玻璃。場景用清透晨光同冷暖平衡。感覺似現代休閒手遊。

兩個方向共通：
- 團絨、場景物件同 icon 保持像素：場景 1x ×3 nearest，icon ×2 nearest。
- UI 框、線同字用 @3x 原生平滑畫。
- 頭像沿用 B ×2 近鏡同 `portrait_rects.json`，跟寵物狀態同埋飾品出框同步。頭像每粒 sprite 像素 = 5 個 @3x px，即 110px 框。
- 版位分區跟 v2：0→42→348→422 art px，即 @3x 0→126→1044→1266，花園佔 73%。

## 字型（都係 SIL OFL 1.1，box 已有）
- Noto Sans CJK TC Regular／Bold：內文、數值、按鈕、細字。
- Noto Serif CJK TC Bold：V3-A 名同標題。
- 上線要做繁中子集，大約 2–3k 字，加 woff2；字重建議另外加 Medium。可以選用 Noto Sans TC／Noto Serif TC 嘅 Google Fonts 子集版本。
- Fusion Pixel 退役，唔再做 UI 字；如果想保留少少像素味，可以只用喺數字特效（例如 +5 飄字）。

**對比**（contrast.json）：V3-A 同 V3-B home 全部字最低 5.05；屋仔最低 4.6（標題）。全部 ≥4.5。做法：字只放喺面板、膠囊或者漸層遮罩上面，唔會直接壓喺場景；陰影用模糊 drop shadow，唔用硬描邊。

## 引擎點畫（canvas2D）
1. **分層**：(a) 像素場景用 offscreen canvas，`imageSmoothingEnabled=false`，整數倍放大；(b) 光影後期層；(c) UI 平滑層，`imageSmoothingEnabled=true`，按 devicePixelRatio 原生解析度畫。
2. **烘焙 vs 即時**：每個場景嘅調色、體積光、bloom 同地板反射全部離線烘焙成一張 @3x「lit」底圖，每個時段一張，零即時成本。即時只畫：光點／粒子（大約 40–110 粒，`globalCompositeOperation='lighter'` 加預畫光暈 sprite）、燈泡呼吸光暈、星芒閃爍、寵物腳下柔光。
3. **磨砂玻璃**：概念用真 alpha 加背景模糊。引擎唔好逐幀做 `ctx.filter='blur()'`（Android WebView 好慢），改用每個場景預先烘焙一張模糊底圖：面板範圍 `drawImage` 嗰張模糊圖，再疊半透明色同漸層。寵物行過面板底時唔會即時模糊；概念上可以接受，因為面板唔遮寵物活動範圍。
4. **真 alpha**：v2 規定「遮罩／光暈用棋盤 tile、唔用半透明」喺 v3 取消。UI 同光影層可以用真 alpha；只有像素 sprite 本身保持 alpha 0／255。
5. **幼線**：1.5px @3x 金線用 `lineWidth = 0.5 * dpr`，座標對 0.5 px 避免糊；圓角用 `roundRect`。
6. **字**：`ctx.font` 用 Noto Sans/Serif TC，按 dpr 畫；影用 `shadowBlur=2*dpr`，唔用 strokeText。
7. **icon**：像素 icon 用 ×2 nearest；同場景 ×3 像素格唔同，係刻意嘅現代 HD-2D 混合做法。
8. **效能預算**：大約 1 張 lit 底圖、1 張 blur 底圖、≤120 粒子、≤20 光暈，每幀 drawImage 大約 200 次。中階 Android 預計 60fps；低階機可以關粒子同光暈。

## 揀邊個
推薦 **V3-A**，原因：
- 深底金幼線無論喺光猛定暗嘅場景都穩定讀到，夜晚、夢遊、屋仔都可以沿用。
- 明朝標題加金飾有「高級 RPG」感，最貼「新派 HD-2D」。
- 繼承 v2 嘅金同深藍，玩家唔會覺得換咗另一隻 game。
V3-B 最清爽、最似休閒手遊，但白玻璃喺光猛天空、雪地或者白牆屋仔會冇咗層次，夜景亦要另外做一套深色版。

## 寵物光源規則（Kurt 2026-11-02：「除左佢訓就會關」）
- 適用範圍：團絨同細佬身上所有光源同特效。包括身體／rim 柔光、腳下光圈、自發光部位（尾光、星芒、光環 bloom）、身邊光點粒子，同埋頭像窗嘅高光閃。
- **醒住**：全部常亮。
- **瞓覺**：全部熄。包括 `sleep` 狀態同 sleep clip、屋仔瞓床、夢遊（6c）入夢前個段瞓著，同埋入夢轉場開始之前。
- **醒返先亮**。
- 過渡用 keyframe，唔好一下熄：
  - 入睡淡出：0 → 600 ms，光強 1 → 0，ease-in；粒子即刻停產，已經有嘅粒子自然消失。
  - 醒返淡入：0 → 400 ms，光強 0 → 1，ease-out；之後加一下 150 ms 小閃（1 → 1.15 → 1）表示醒咗。
  - `sleepy`（眼瞓但未瞓）唔熄，光強降到 0.6。
- 場景燈（燈泡串、街燈、屋仔燈、窗光）唔跟寵物熄；只係寵物自己嘅光熄。
- 引擎做法：用一個 `petGlow ∈ [0,1]` 乘晒所有寵物光層嘅 alpha 同粒子產生率。烘焙底圖唔包寵物光，所以可以即時控制。
- 美術：v3 所有寵物 clip 嘅光層要分開出（`*_glow` 層），唔好燒落 sprite。sprite 本身保持 alpha 0／255。
