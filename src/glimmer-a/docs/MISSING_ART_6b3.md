# 6b.3「UI 縮細＋收埋」美術缺件清單

6b.3 冇新增必要美術：縮細用 CSS `scale`（0.8333）縮現有 ui62 素材，點陣字 GlimmerFP12 保持 24 CSS（12 倍數，唔糊），有效 20。
「收埋 UI」掣暫時用 canvas 自己畫嘅 10×7 點陣眼（開眼＝收埋、閉眼＝顯示）＋ 30px 金邊圓。全部原創，唔用第三方素材。
