# 小遊戲 v2（遊策 2026-11-01 10:00）— 回應 Kurt「重複同埋好似文字遊戲」
原則：直向單手、即時動作、每局 ≤45 秒；冇文字按鈕，只用手勢同 icon；每局隨機 2 個變化（天氣、速度、特別物）；團絨全程有反應（得意、扮冷靜、跌低、嬲嬲）。獎勵同 v1 一樣（1–3★＝1–3 碎，計火苗 +2）。

1. 彈彈葉（新）：用手指撳住葉片彈床儲力、放手彈起團絨，喺半空左右拖，掂光點得分。團絨會自信咁翻筋斗然後跌錯位。風向、雨雲、金光點每局唔同。
2. 張口接光（重做接光點）：直接拖團絨左右走，用口接跌落嚟嘅光點，唔再係拖個籃。連續接中會越嚟越囂張；斷 combo 就絆親自己。落雨時光點會斜住跌，夜晚就會跌螢火。
3. 花園捉迷藏（重做）：真花園場景，團絨匿喺花盆、葉堆、石後面，會郁、會露出尾巴同燈泡；撳下就搖嗰樣嘢。你太慢佢會偷偷轉位，每回合位置同遮擋物都唔同；搵到佢會扮冇事咁行出嚟。
4. 頭頂疊疊（新）：團絨頭頂疊果，左右擺手機（或者拖）保持平衡；佢自己一路要再加，越疊越高。
5. 追螢火（新，夜晚限定）：用手指畫一條路，團絨跟住條路衝去捉螢火，中途撞樹枝會扮冇痛。

建議：1＋2＋3 做第一輪（2、3 可以用返現有素材改，最快）；4、5 之後先加。
