# audio/ — 音效與配樂規格

負責：遊音。呢份係音訊規格同清單。BGM 暫時只有規格，冇音檔；`sfx/` 有 8 個基本音效。

> **遊戲類型**：repo 暫時未有正式 GDD（`docs/gdd/` 仍然係空）。以下風格方向根據遊策嘅草稿《風野競走（暫名 Windrun）》：休閒至中度策略、養成同自動賽跑、浮島風同野靈主題。草稿未經 Kurt 確認，如果之後改類型，BGM 方向同 SFX 清單會跟住更新。基本 SFX 本身係通用嘅 UI 同回饋音效，唔受類型影響。

## 1. 檔案規格

| 類別 | 格式 | 取樣／聲道 | 響度 | 峰值 | 長度 | 命名 |
|---|---|---|---|---|---|---|
| BGM | ogg（Vorbis） | 44.1 kHz，立體聲 | 目標 -16 LUFS（integrated） | true peak ≤ -1 dBTP | 見下表，必須可無縫循環 | `bgm_<scene>_loop.ogg`，例 `bgm_menu_loop.ogg` |
| SFX | ogg 或 wav | 44.1 kHz，單聲道 | 約 -12 LUFS（短音，近似值） | peak ≤ -1 dBFS | 0.1–2 秒 | `sfx_<name>.ogg`，例 `sfx_tap.ogg` |

- 全部用 snake_case 細楷命名，只用 `a-z`、`0-9`、`_`。
- BGM 循環點要喺零交叉或者已經做 crossfade，唔可以有 click。
- 長度只係建議範圍。BGM 以完整小節收尾。

## 2. BGM 風格方向

| 場景 | 檔名 | 風格方向 | 速度 | 循環長度 |
|---|---|---|---|---|
| 主選單 | `bgm_menu_loop.ogg` | 輕盈、空曠、帶少少期待。木琴、豎琴、柔和 pad，加輕微風聲。主要用大調。 | 80–95 BPM | 30–45 秒 |
| 賽事／遊戲中 | `bgm_gameplay_loop.ogg` | 明快、向前衝。輕快打擊、撥弦、短旋律，節奏要清楚但唔搶 SFX。大招同換人嗰刻留空間畀音效。 | 120–135 BPM | 60–90 秒 |
| 勝利 | `bgm_win_loop.ogg` | 明亮、慶祝。大調上行旋律，鐘琴同弦樂。 | 100–110 BPM | 15–20 秒，可循環當結算畫面底樂 |
| 失敗 | `bgm_lose_loop.ogg` | 輕微失落但唔沉重，要鼓勵再試。小調、慢速、簡單鋼琴同 pad。 | 70–80 BPM | 15–20 秒 |

進度：以上四首**暫未製作**，等風格同類型確認後先做。

## 3. SFX 清單（已提供）

| 檔名 | 觸發 | 長度 | 備註 |
|---|---|---|---|
| `sfx_tap.ogg` | 一般按鈕、頭像點擊 | 0.12 s | 短促高音 click，會好頻密出現，要唔刺耳 |
| `sfx_confirm.ogg` | 確認、開始賽事、升級 | 0.32 s | 兩音上行（大三度加完全四度） |
| `sfx_cancel.ogg` | 取消、返回、關閉彈窗 | 0.29 s | 兩音下行，比 confirm 柔和 |
| `sfx_coin.ogg` | 拾取貨幣、獎勵 | 0.46 s | 兩音閃亮音，高頻帶泛音 |
| `sfx_hit.ogg` | 碰撞、被壓制、大招命中 | 0.18 s | 低頻下滑加短噪音 |
| `sfx_win.ogg` | 賽事勝利 jingle | 1.64 s | 四音上行琶音收長和弦 |
| `sfx_lose.ogg` | 賽事失敗 | 1.34 s | 下行音加低頻滑落，柔和 |
| `sfx_error.ogg` | 操作無效、資源不足 | 0.33 s | 兩下低沉短嗡聲 |

量度（ffmpeg）：全部 44.1 kHz 單聲道 Vorbis，true peak 介乎 -1.6 至 -4.9 dBFS，總共約 72 KB。短音以重複播放方式估算響度，結果約 -12 LUFS，個別音效（coin、win）略低，屬正常。

## 4. 生成方式

`audio/tools/gen_sfx.py` 用 numpy／scipy／soundfile 以程式合成波形，`audio/tools/norm.py` 負責響度同峰值處理，之後用 ffmpeg 轉成 ogg：

```
ffmpeg -i in.wav -ac 1 -ar 44100 -c:a libvorbis -q:a 3 out.ogg
```
