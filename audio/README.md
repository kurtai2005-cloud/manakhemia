# audio/ — 《微光小圃》音效與配樂

負責：遊音。依據 `docs-gdd/pet-one-pager.md`（Kurt 已批准）：溫柔、治癒嘅夜間小園圃，4 項需求（餵食／玩耍／清潔／睡眠）、3 個迷你遊戲、5 個階段（光卵→芽崽→跳跳期→守夜者→靜光）。

**MVP 範圍**：1 首照顧 BGM（`bgm_care_loop.ogg`）＋ 餵食／玩耍／清潔／睡眠／迷你遊戲基本 SFX ＋ 孵化／進化／化光 3 個 jingle。其餘列為「待做」，唔阻 MVP。

**方案 A（加深）音訊**：見第 7 節（① 寵物聲、② 事件音、③ 時段 BGM、④ 環境互動全部已做；全部未有人親耳聽過）。

## 1. 檔案規格

| 類別 | 格式 | 取樣／聲道 | 響度 | 峰值 | 長度 | 命名 |
|---|---|---|---|---|---|---|
| BGM | ogg（Vorbis） | 44.1 kHz，立體聲 | -16 LUFS（integrated） | true peak ≤ -1 dBTP | 見第 2 節，完整小節，必須無縫循環 | `bgm_<scene>_loop.ogg` |
| SFX | ogg（Vorbis） | 44.1 kHz，單聲道 | 約 -12 LUFS 為參考；頻密出現嘅音刻意更細聲（見第 3 節實測） | sample peak ≤ -1 dBFS | 0.1–2 秒 | `sfx_<name>.ogg` |
| Jingle（孵化／進化／化光／搖籃曲） | 同 SFX | 同 SFX | 同 SFX | 同 SFX | **例外：最長 3 秒** | `sfx_<name>.ogg` |

- 命名只用 `a-z`、`0-9`、`_`（snake_case）。
- 響度量度：BGM 直接量整首；SFX 短過 0.4 秒，gated 響度計唔穩定，所以用「重複播放約 4 秒（每次間隔 0.1 秒）」量度，係近似值。全部數值喺解碼後嘅 ogg 上用 `ffmpeg ebur128=peak=true` 量，唔係估算。
- **程式整合提示**：BGM 用 sample-accurate loop（唔好用有 gap 嘅串流／MP3）。ogg 已確認解碼後樣本數 = 循環長度（3,112,941 samples），接縫處連續。場景切換建議 1–2 秒 crossfade。`sfx_mg_catch` 連擊可用 playbackRate 1.0／1.189／1.335／1.587（+0／3／5／8 半音），音高仍喺五聲音階內。

## 4. 無縫循環做法（BGM）

全部聲音先渲染到「循環長度＋7 秒尾巴」，尾巴疊返落開頭（overlap-add）；殘響、空氣聲濾波用 FFT 圓周運算，所以尾端自然接回開頭。驗證（解碼後 ogg）：總樣本數剛好 = 20 小節；接縫處樣本差（0.011／0.020）細過全曲 99.9 百分位差（0.033／0.029）；接縫前後 50 ms RMS 冇突變。

### 7.1 ① 寵物聲（團絨，已做）

**Crossfade 整合說明（遊程）**：
- 所有 loop 嘅**第 k 小節（k 由 0 起）和弦同 `bgm_care_loop` 第 k 小節完全一樣**（照顧版和弦＝ `A A B A A`，每組 4 小節：A＝Cmaj7–Am7–Fmaj7–G6，B＝F–G–Em7–Am7）。早／晚用頭 16 小節（A A B A），夜用頭 12 小節（A A B）。所以同一小節位置切換和聲一定對得上。
- 小節長度 **3.5294 s（240/68）**；小節線時間 = k × 3.5294 s（**每小節 155,647.06 samples，唔係整數，請用時間（秒）排程，唔好用整數樣本倍數累加**，否則 16 小節後會漂移 ≤1 sample，聽唔到但唔好累積）。
- 建議切換規則：當前 loop 播緊第 b 小節（b = 播放位置 ÷ 3.5294 s，取整）→ 喺**下一條小節線**開始 1–2 秒 equal-power crossfade，目標 loop 由第 **(b+1) mod 目標小節數** 小節開始播。因為和弦係 4 小節一組（A A B A A），而各 loop 嘅循環長度（12／16／20）都係 4 嘅倍數，所以 (b+1) mod 長度 嘅和弦同 b+1 小節（以 base 計）一致，只有一種情況唔同：**base 第 16–19 小節**（A 組）對 12 小節夜 loop 為第 4–7 小節（A 組，OK）；對 16 小節早／晚 loop 為第 0–3 小節（A 組，OK）。即：A 組只會對 A 組；B 組（base／早／晚／夜 第 8–11 小節）只會對 B 組。（base 20 小節 ＝ A A B A A，早／晚 ＝ A A B A，夜 ＝ A A B。）
- 響度：早／正午／晚同為 -16 LUFS，可直接 crossfade；夜 -22 LUFS（細 6 LU）。夜間做睡眠狀態可再配 `sfx_pet_sleep_breath_loop`（-22）。時段邊界由遊程決定；建議用玩家在場時 crossfade，唔好硬切；crossfade 期間兩條都播，用 equal-power 曲線（sin／cos）。
- 同一時間只播一條 BGM（crossfade 時段除外）；`sfx_env_sunbathe_loop` 可疊喺任何一條上（見 7.5）。

**偏差（如實）**：
1. 早／晚目標響度：原本 7.4 表寫 -17／-18 LUFS，今次按任務指示統一做 **-16 LUFS**（同正午一致，crossfade 唔使調音量）；夜 -22 LUFS 不變。需要早／晚更細聲可喺程式調音量。
2. 夜 loop 實測 TP -11.4 dBTP，遠低於上限（-4 dBTP），因為係極輕嘅 pad，唔係壓縮嘅結果。
3. 唔係 stems（一條立體聲 loop）；遊程如要逐層混音再同我講。

**觸發建議**：
- 雨層開始：播 `short`（淡入部分），約 1.5 s 後喺 `short` 仲響緊時 crossfade（約 1–2 s）入 `loop`；或者直接由 0 淡入 `loop`（1.5–2 s）。
- 雨層期間：`loop` 必須 **sample-accurate 無縫循環**（Web Audio `AudioBufferSourceNode.loop=true`／Godot `AudioStreamOggVorbis.loop=true`，loop_offset 0；唔好用 `<audio>` 元素 loop，會有空隙）。
- 停雨：`loop` 淡出 1.5–2 s；或者淡出 `loop` 同時播 `short` 嘅後半段（由 4.0 s 開始）。
- 短陣雨：淨係播 `short` 一次。
- 同時段 BGM 一齊播（BGM -16、夜 -22 LUFS）；雨唔使 duck 寵物聲。如夜間（-22 LUFS BGM）覺雨太突出，程式降 3–4 dB 即可。

**循環驗證（`measure_amb.py`，解碼後）**：樣本數 1,089,529（＝ 7.000 小節）；接縫樣本差 L/R＝0.0007／0.0179，細過全檔相鄰樣本差 99.9 百分位 0.0965／0.0965（最大 0.240）；接縫前後 50 ms RMS 0.0357／0.0299（慢速強弱起伏範圍內）。全部成分喺 FFT 圓周域合成，所以冇 crossfade 痕。

**short 淡入淡出**：首 0.1 s RMS -75.4 dBFS → 1.5–4.0 s -28.4 dBFS → 5.0–5.5 s -38.4 → 最後 0.1 s -81.0；首／尾樣本 0。

**偏差（如實）**：
1. short 嘅 -24.0 係整檔 integrated；全音量段 1.5–4.0 s 實測 -23.0，比 loop 大約 1.0 LU，crossfade 入 loop 時差異細。
2. 250–400 Hz 仍佔 21–23 %（刻意留少少身位，唔想淨係得高頻「沙沙」）；如仍覺悶，可再減。
3. 2–6 kHz 加強咗，最大風險係變成「沙沙」底噪／煎嘢聲而唔似雨。
4. TP -7.8／-9.8 dBTP，遠低於 -1 上限，因為雨聲冇大峰值，唔係壓縮結果。

**未有人聽過**——尤其：似唔似細雨（定似沙沙底噪）、2–6 kHz 會唔會刺耳、雨滴會唔會喺 loop 入面聽得出重複。
