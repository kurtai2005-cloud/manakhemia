# 上架前檢查清單

> 每項打 ✅（通過）／❌（失敗，請連結 bug ID）／➖（不適用）。

## 操控
- [ ] 觸控：點擊、拖曳、多點觸控回應正常，無漏掃或誤觸
- [ ] 按鈕大小足夠（建議 ≥ 44×44 px），安全區域（瀏海／圓角）不被遮擋
- [ ] 直／橫屏切換（如支援）UI 不錯位

## 效能
- [ ] FPS：目標機種穩定 ≥ 30（理想 60），無明顯卡頓
- [ ] 載入時間：冷啟動及關卡載入在可接受範圍
- [ ] 記憶體：連續遊玩 30 分鐘無持續增長（無洩漏）
- [ ] 電量／發熱：連續遊玩 30 分鐘耗電及發熱合理

## 相容性
- [ ] 多種螢幕尺寸／解像度／長寬比（小屏、大屏、平板）顯示正常
- [ ] 低階及高階裝置各試最少一部

## 穩定性
- [ ] 無閃退／卡死；來電、切換 App、鎖屏後可恢復
- [ ] 斷網／弱網情況行為合理，存檔不損毀

## 權限與私隱
- [ ] 只申請必要權限，並附清楚用途說明
- [ ] 私隱政策連結有效；數據收集聲明與實際一致

## 商店合規
- [ ] 年齡分級問卷、內容分級填寫正確
- [ ] 無第三方版權素材（美術、音訊、字型皆有授權）
- [ ] 內購／廣告（如有）符合 App Store／Google Play 政策
- [ ] 商店資料（名稱、圖示、截圖、描述）齊備
