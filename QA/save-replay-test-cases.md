## 3. 重播（同種子重播一致，驗收⑥）
### 3.1 已驗證（`determinism_check.js`，windrun-proto 模擬層，300 場隨機 3v3×全部賽道）
| 檢查 | 結果 |
|---|---|
| 同種子連跑兩次（勝方、時長、換人、技能、終點差） | 0／300 不同 |
| 唔同幀率切片（30／60／144／47 fps，累積器每 `sim_dt` 步進） | 0／300 不同 → **模擬同表現分離成立** |
| 帶輸入日誌（指定步數換人／放技能）於 60／30 fps 重播 | 0／300 不同 |
| 重播檔 JSON 序列化往返後重播 | 0／300 不同 |
| `sim.js`／`data.js` 靜態掃描無 `Math.random`／`Date`／`performance.now` | 乾淨 |
| 時長 ≤120 s | 最長 106.8 s，0 場超時 |
| 瀏覽器真實環境：凍結種子，「高檔 4× 倍速」vs「低檔 6× 限速」 | 結果逐位相同（98.2918 s、終點 987.587／1000.077） |
